# Dragon Ball GT: Final Bout Recompiled 1.0.1

Fresh settings enable the shared Internal Resolution mod at 4x, with 1x through
32x choices subject to GPU texture and memory limits. Saved choices remain
authoritative; disabling the mod selects native resolution. The old title-owned
1080p default is removed so it cannot override the mod.

The engine adopts the reviewed shared optimization defaults. Releases use the
maintained common builder with fresh title-specific selective PGO and a verified
public archive. CD Speed and Fast Loading packages are excluded. This adoption
does not establish a new per-title runtime speedup or broader gameplay/netplay
qualification.

Adaptive widescreen, the digital-pad lock, native memory cards, netplay and
FuniDub remain available. The original FuniDub UI revision is retained because
it provides owned preparation progress and cooperative cancellation. The native
voice builder, recipe, expected hashes and original-audio fallback are unchanged.
Players still supply their own Final Bout disc and optional BT3 ISO; neither
game media nor prepared recordings are shipped.

Native memory-card progress is separate from disposable build-specific snapshots.
Existing known limitations and unqualified voice/progression coverage remain in
the project documentation. No old snapshot migration is required.
