# Dragon Ball GT: Final Bout Recompiled v1.0.0

The first Windows x64 release brings Final Bout to PC with:

- **Adaptive widescreen** through 21:9, with adjusted HUD and stage backgrounds.
- **FuniDub**, an optional English voice mod prepared locally from your own
  USA Budokai Tenkaichi 3 ISO. Includes character introductions, combat sounds,
  attack calls and victory lines, with a reusable local cache.
- **Two-player netplay** powered by recomp-net: online lobbies and LAN / direct
  IP, alongside local versus.
- Higher internal resolution, controller configuration and save states.

Extract the entire Windows ZIP and run
**DragonBallGTFinalBout_Recompiled.exe**. Select your own **USA Final Bout
CUE + BIN image (SLUS-00493)** when prompted. OpenBIOS and portable setup tools
are included; no compiler or Python installation is required.

Enable widescreen and FuniDub in the launcher's **Mods** page. FuniDub additionally
requires your own **USA PS2 Budokai Tenkaichi 3 ISO (SLUS-21678)** for the initial
import. No game media or voice recordings are included in this release.

Both netplay players should use the same release, supported disc and compatible
mod selections. FuniDub content must be prepared locally by each player.

Some voice lines use generic substitutions or retain original audio, and mouth
animation timing can differ. This release has focused gameplay and multiplayer
checks; some scenes, effects and progression routes remain untested. Please
[report issues](https://github.com/mstan/DragonBallGTFinalBoutRecomp/issues)
with your settings and reproduction steps.
